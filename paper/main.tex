\begin{abstract}
History is an attractive answer key for evaluating strategic reasoning: a decision made with information available in 1996 can be scored against what actually happened afterwards. Large language models (LLMs) make this answer key leaky, because they already know the history. We introduce \sys{}, an open protocol in which a simulated startup, voiced by sixteen LLM role personas, must reinvent itself across nine technology eras from 1990 to 2040. In six \emph{training} eras (1990--2020) the organization decides using only dated information; an LLM historian-judge then reveals what happened, scores the call on five dimensions, and appends lessons to a Playbook that carries forward. In one live era (September 2026) and two forecast eras (2032, 2040) there is no answer key. We report four exploratory trajectories (36 era decisions, 180 subscores) produced under three orchestration schemes. In all four, training-era scores rise across eras ($+1.4$ to $+2.6$ points per era) while the judge's own hindsight-leakage subscore worsens in the same eras (per-run Pearson $r$ between total and hindsight subscore from $-0.38$ to $-0.92$, $n=6$ each), so apparent learning cannot be separated from recall. Layer choice is the lowest-scoring dimension in every run, consistent with a qualitative pattern in which the organization named the coming capability shift but chose an adjacent, asset-reachable layer. We also document measurement failures that any ``learn from history'' agent benchmark should expect: inconsistent score aggregation, a column-shift error in exported scores, probable cross-run contamination, briefing-selection leakage, and a rubric that rewarded one run for fifty years of gated, never-built pilots. We release all prompts, run records, scores and an API harness with ablations, and we specify a controlled follow-up design with pre-registered hypotheses.
\end{abstract}

\section{Introduction}

How well can an LLM-based organization reason about technological change? Existing multi-agent systems show that role-structured LLM agents can collaborate on software, simulation and open-ended tasks \citep{park2023generative,qian2024chatdev,hong2024metagpt,li2023camel,chen2024agentverse,guo2024survey}, and LLM forecasting systems now approach human crowds on some question sets \citep{halawi2024forecasting,karger2024forecastbench}. Strategy, however, is harder to evaluate than code or calibrated probabilities. The quality of a strategic call is usually revealed years later, if at all.

History offers an answer key. If an organization decides in January 1996 using only what was public then, we can compare its decision with what happened from 1996 to 2001. This is the logic of backtesting in finance and of retrospective forecasting benchmarks. For LLMs the key is leaky: a model trained on text written after 1996 knows which companies won. The problem is well known for question-answering benchmarks and forecasting evaluations \citep{sainz2023trouble,golchin2024timetravel,cheng2024dated,glasserman2023lookahead,paleka2026pitfalls}. It is sharper for open-ended strategy, where the model's own reasoning chooses what to mention and an LLM judge decides what counts as foresight.

This paper presents \sys{}, a protocol and set of artifacts for studying that problem in a setting that is deliberately open-ended. One simulated company, voiced by sixteen named role personas and two external judges, must reinvent itself in each of nine eras. The judge scores every decision, and the organization carries lessons forward in a Playbook, so we can ask whether scores improve over eras and why.

We report four exploratory trajectories. They are not a controlled experiment, and we are explicit about why. Their value is in what they reveal about measurement:

\begin{itemize}
  \item \textbf{Learning and leakage move together.} In every run, training-era scores rise while the hindsight subscore worsens in the same eras (Section~\ref{sec:leakage}).
  \item \textbf{A consistent weakness in layer choice.} Across all runs, the judge rates layer choice lowest, matching a qualitative pattern of ``naming the frontier, then building the adjacent layer'' (Section~\ref{sec:layer}).
  \item \textbf{Rubrics can reward paralysis.} One run scored highest while never building a product in fifty simulated years (Section~\ref{sec:caution}).
  \item \textbf{Mundane measurement failures matter.} Inconsistent aggregation, an export error and probable contamination between runs each change what the data appear to say (Section~\ref{sec:artifacts}).
\end{itemize}

\paragraph{Contributions.} (1) An open protocol for scoring agent-organization strategy against dated history, with role charter, per-era loop, rubrics and anti-hindsight rules. (2) Four fully published trajectories (36 era decisions) including every briefing, memo, board decision and reveal where available, one disclosed operator intervention and all redactions. (3) An analysis of hindsight leakage and related measurement failures as confounds for any ``learn from history'' agent benchmark. (4) A controlled follow-up design with pre-registered hypotheses, ablations, leakage controls and judge-validity checks, supported by an open API harness.

\section{Related work}

\paragraph{LLM agent societies.} Role-playing and multi-agent frameworks assign LLM instances roles and communication protocols to solve tasks or simulate social behaviour \citep{park2023generative,li2023camel,qian2024chatdev,hong2024metagpt,chen2024agentverse}; see \citet{guo2024survey} for a survey. Multi-agent debate can improve factuality and diversity of reasoning \citep{du2024debate,liang2024divergent}. Agents that accumulate verbal lessons or skill libraries across episodes \citep{shinn2023reflexion,wang2023voyager} are the closest analogue to our Playbook. We differ in evaluating a sequence of strategic decisions against real historical outcomes rather than task success.

\paragraph{LLMs as simulated humans and organizations.} LLMs have been used as simulated economic agents \citep{horton2023homo} and survey respondents \citep{argyle2023outofone}. Our organization is a simulated firm; like these works we treat its outputs as model behaviour, not as evidence about real firms.

\paragraph{LLM-as-a-judge.} LLM judges agree with human preferences on many tasks but show position and verbosity biases \citep{zheng2023judging,wang2023notfair} and favour their own generations \citep{panickssery2024selfpref}. In all our runs the judge shares a model family with the players, and in one run the same context wrote the decisions it judged.

\paragraph{Contamination, cutoffs and temporal leakage.} Benchmark contamination can inflate scores \citep{sainz2023trouble,golchin2024timetravel}, effective knowledge cutoffs differ from reported ones \citep{cheng2024dated}, and LLM-based backtests suffer look-ahead bias \citep{glasserman2023lookahead}. \citet{paleka2026pitfalls} catalogue pitfalls in evaluating LLM forecasters, including temporal leakage in retrospective evaluation. Our setting adds leakage through the choice of what a dated briefing mentions and through a judge that labels foresight after the fact.

\paragraph{Forecasting benchmarks.} Autocast \citep{zou2022autocast}, retrieval-augmented forecasting systems \citep{halawi2024forecasting} and ForecastBench \citep{karger2024forecastbench} evaluate probabilistic forecasts of resolvable questions, following the tradition of \citet{tetlock2005expert,tetlock2015superforecasting}. Strategy decisions are not resolvable questions, which is why we rely on a judge and why judge validity matters.

\paragraph{Organizational learning and strategy.} The protocol operationalizes ideas from organizational learning \citep{levitt1988organizational}, the exploration--exploitation trade-off \citep{march1991exploration}, absorptive capacity \citep{cohen1990absorptive}, dynamic capabilities \citep{teece1997dynamic} and disruptive innovation \citep{christensen1997innovator}. Its Red Team draws on devil's-advocacy research \citep{schwenk1990devils} and the risk of groupthink \citep{janis1972groupthink}. Hindsight bias in human judgment \citep{fischhoff1975hindsight,roese2012hindsight} is the human analogue of the leakage we study.

\section{The \sys{} protocol}

\subsection{Eras}

A single company is carried through nine eras (Table~\ref{tab:eras}). Its only mandate is \emph{reinvention toward the frontier}: in each era it should become the most important company that era could produce, even if that means ending its current business. Training eras are scored against real history over a roughly six-year window. The live era is scored by an auditor who checks claims against the current market with web search. Forecast eras have no answer key.

\subsection{The per-era loop}

Figure~\ref{fig:loop} and Algorithm~\ref{alg:loop} summarize one era. The judge writes a dated world briefing. Three departments write memos in parallel, each proposing two theses as the chain \emph{capability $\rightarrow$ adoption $\rightarrow$ bottleneck $\rightarrow$ layer owned $\rightarrow$ data $\rightarrow$ next capability}. The board meets, the Red Team attacks, and the CEO decides the company's identity, thesis, what it kills and keeps, its wedge product, kill criteria and a dissent log. The judge then reveals what happened (training) or audits the claims (live and forecast), scores the call, and appends lessons to the Playbook. The judge also writes the next era's briefing.

\begin{algorithm}[t]
\caption{One \sys{} trajectory}
\label{alg:loop}
\small
\begin{algorithmic}[1]
\Require charter $C$, eras $E_1,\dots,E_9$, player model $\pi$, judge model $J$
\State $S \gets$ initial company state (\$1.5M seed, 16 personas); $P \gets \emptyset$ \Comment{Playbook}
\State $B_1 \gets J.\textsc{Briefing}(E_1)$ \Comment{only facts dated before $E_1$}
\For{$k = 1$ to $9$}
  \For{$d \in \{\text{frontier}, \text{product}, \text{market}\}$ \textbf{in parallel}}
    \State $M_d \gets \pi.\textsc{Memo}(d, C, S, P, B_k, D_{k-1}, R_{k-1})$ \Comment{two theses each}
  \EndFor
  \State $(D_k, S) \gets \pi.\textsc{Board}(C, S, P, B_k, \{M_d\}, \textit{red\_team}=\text{on})$
  \If{$E_k$ is a training era}
    \State $(R_k, \mathbf{s}_k, L_k) \gets J.\textsc{Reveal}(D_k, \text{history in window of } E_k)$
  \Else
    \State $(R_k, \mathbf{s}_k, L_k) \gets J.\textsc{Audit}(D_k)$ \Comment{web search in $E_7$}
  \EndIf
  \State $P \gets P \cup L_k$; \quad $S \gets S \oplus \text{outcome}(R_k)$
  \State $B_{k+1} \gets J.\textsc{Briefing}(E_{k+1})$ \Comment{projected world for $E_8, E_9$}
\EndFor
\State \Return $\{D_k, R_k, \mathbf{s}_k\}_{k=1}^{9}$, $P$
\end{algorithmic}
\end{algorithm}

\subsection{Rules}

Five rules apply throughout. \emph{Anti-hindsight}: in training eras, memos and decisions may use only information public before the era's start date, enforced by the Red Team and penalized by the judge. \emph{Reinvention by default}: keeping the previous business must be argued for. \emph{Layer thinking}: every thesis states the full chain above. \emph{Small-team realism}: the wedge must be buildable by fewer than twenty people with era-realistic capital. \emph{Playbook primacy}: from E2, every memo cites at least one Playbook lesson or argues against it.

\subsection{Rubrics and aggregation}

The judge assigns five subscores $s_{k,1},\dots,s_{k,5} \in \{0,\dots,10\}$ and a total $T_k \in [0,100]$. Training eras use frontier accuracy, timing, layer choice, reinvention courage and hindsight leakage (10 = no leakage). Live and forecast eras use playbook consistency, plausibility, non-consensus, layer choice and groundedness (10 = no science fiction). The protocol did not fix how $T_k$ relates to the subscores. We therefore report both the published total and the mechanical aggregate
\begin{equation}
  \tilde{T}_k = 2 \sum_{j=1}^{5} s_{k,j},
\end{equation}
which ranges over $[0,100]$. Section~\ref{sec:artifacts} shows why the distinction matters.

\subsection{Learning and leakage are confounded}
\label{sec:leakage}

If the Playbook helped the organization learn, scores should rise over eras. They do. But the judge's hindsight subscore falls in the same eras: every run shows a negative correlation between the era total and the hindsight subscore (Table~\ref{tab:summary}, Figure~\ref{fig:leak}). The correlation remains negative for the mechanical aggregate $\tilde{T}$, even though $\tilde{T}$ includes the hindsight subscore itself and is therefore biased toward a positive correlation. With $n=6$ per run none of these correlations is individually reliable, but the direction is the same in all four.

Two readings fit the data. Under the \emph{learning} reading, the organization genuinely improves, and later eras also happen to be harder to judge without hindsight. Under the \emph{leakage} reading, later eras are closer to the model's densest knowledge (the 2008--2020 technology history is heavily documented), so the model recalls winners more easily, scores better, and is penalized for it only partly. The Run 001 E6 decision illustrates the problem: its tripwire (``a public model at least ten times larger than Megatron that works from prompts alone'') matched GPT-3 five months later. That decision was also written by the operator, not the agents, so it is doubly uninformative. Separating the two readings requires eras the model cannot remember (Section~\ref{sec:v2}).

Pooled across the 24 training eras, the total--hindsight correlation is weaker ($r=-0.24$) because run-level offsets differ: Run 004 has both the highest mean hindsight subscore (7.33) and the highest mean total. Within the pool, frontier accuracy is the subscore most correlated with the total ($r=0.67$).

\subsection{Layer choice is consistently weakest}
\label{sec:layer}

Figure~\ref{fig:sub} shows mean training subscores. Layer choice is the lowest dimension in every run (4.67, 5.83, 5.50 and 5.50 out of 10), while frontier accuracy is the highest or joint highest in three runs. In the judge's words, the organization usually saw what was coming but chose where to stand badly.

Run 001's records make the pattern concrete (Table~\ref{tab:adjacent}). In most training eras a department memo named the capability shift that the judge later identified, and the board chose the layer its existing assets could reach. E3 is a counterexample: the judge found that no memo named that era's largest shifts (social networks, cloud computing and mobile). This is consistent with absorptive-capacity and exploration--exploitation accounts of firms that search near existing competences \citep{cohen1990absorptive,march1991exploration}. Two caveats apply. ``Named'' and ``adjacent'' are the judge's labels, applied with hindsight. And because Runs 002--004 probably saw Run 001's conclusions, the cross-run agreement on layer choice is weaker evidence than it looks.

\subsection{A caution attractor}
\label{sec:caution}

Run 004 behaved differently from the others. Its Red Team produced numeric kill thresholds in every era (for example, ``stop if fewer than 3 of 10 support managers confirm recurring incidents''), and every board decision chose a manual, gated pilot with no software build until the gates passed. Across fifty simulated years the company moved from LAN support records to online-order exceptions to payment-dispute evidence to independent workflow qualification, and never built a product. It considered the Web and learned models only as deferred options and never pursued them.

Run 004 nonetheless has the highest training mean (66.0) and the highest hindsight subscores (mean 7.33). Its forecast eras received 9/10 for playbook consistency for re-applying the same gates. The rubric rewards the absence of hindsight and the presence of discipline, and it has no dimension that asks whether the company reached where value pooled. This mirrors the ``timid choices'' pattern described for human organizations \citep{kahneman1993timid} and an exploitation trap in March's sense \citep{march1991exploration}: a strong devil's advocate \citep{schwenk1990devils} combined with a hindsight penalty can drive a simulated organization toward inaction that a judge scores as prudence.

\subsection{Convergence of the forecasts}

By 2040 all four runs arrived at closely related theses about accountability for delegated AI work (Table~\ref{tab:converge}). The later runs were more sceptical than Run 001 that software evidence alone creates an insurable market; Runs 002 and 003 explicitly required a licensed risk-bearing partner and calibrated loss data first. Given a shared model family and probable exposure to Run 001, we read this convergence as a model prior reinforced by contamination, not as independent evidence about the future.

\subsection{Measurement artifacts}
\label{sec:artifacts}

\paragraph{Inconsistent aggregation.} The published total follows different rules in different runs (Figure~\ref{fig:agg}). Run 001 totals are holistic and lie below $\tilde{T}$ in eight of nine eras (mean difference $-3.7$). Run 004 uses $\tilde{T}$ exactly, as documented. Run 002 matches $\tilde{T}$ except E6 (72 against 68). Run 003 matches $\tilde{T}$ only in E1 and E2. Comparing published totals across runs therefore mixes rules. Recomputed training means ($\tilde{T}$) are 63.7, 64.3, 62.3 and 66.0, narrower than the published 60.0 to 66.0.

\paragraph{Export error.} In Runs 002 and 003, the five Auditor subscores for live and forecast eras were exported one column to the left, starting in the unused hindsight column. The Run 003 reveals confirm the correct placement. Totals were unaffected, but any subscore analysis of the original files would be wrong. The repository now contains corrected files and a unified long-format table with both totals.

\paragraph{Probable cross-run contamination.} Run 002 reuses Run 001's company names and theses for E1--E4 (Switchyard, Manifest, Ledgerline, Clearline) and restates Run 001's headline finding almost verbatim. Run 004 also begins as ``Switchyard Systems''. These runs were generated in a workspace where the repository, including Run 001's records and findings, was likely visible. They should not be treated as independent replications.

\paragraph{Briefing-selection leakage.} A dated briefing can contain only facts published before the era and still leak, because choosing which facts to include is informed by hindsight. Run 004's 1990 briefing foregrounds the 1989 CERN hypertext proposal as ``a frontier signal''. The fact predates the era; its selection does not.

\section{Discussion}

The pilot does not show that an LLM organization learns strategy from history. It shows why the obvious way of testing that claim is unreliable, and which controls a credible test needs.

First, \emph{rising scores are not evidence of learning} when the scorer and the player share knowledge of the answer. The direction of the total--hindsight relationship was the same in four runs produced under three orchestration schemes. A benchmark that rewards agents for being right about 2008--2020 will partly reward recall.

Second, \emph{the rubric shapes the organization}. Adding hindsight discipline to the total, and giving playbook consistency its own dimension, rewarded a run that took no risks. Rubrics for open-ended strategy need a measure of outcome capture that cannot be satisfied by caution.

Third, \emph{self-judging compounds both problems}. LLM judges favour their own outputs \citep{panickssery2024selfpref}. In our runs the judge also wrote the next briefing, and in Run 001 the E8 judge's kill case became the E9 world, so forecast-era scores partly graded the judge's own scenario.

Fourth, \emph{bookkeeping matters}. The aggregation inconsistency and the export error were each enough to change a naive cross-run comparison. Totals should be computed by code from structured subscores, never typed by the judge.

\section{A controlled follow-up design}
\label{sec:v2}

We specify a v2 experiment, supported by the repository's harness, to test the pilot's hypotheses.

\paragraph{Pre-registered hypotheses.} H1: the training-era slope of the total is higher with the Playbook than without it. H2: the full organization beats a single-prompt founder baseline on mean training score. H3: on a fictional era, the judge's leakage subscore does not differ between conditions, a calibration check for the leakage measure. H4: layer choice is judged ``adjacent'' more often than ``match'' in all conditions.

\paragraph{Conditions and replication.} Four conditions (full, no Playbook, no Red Team, single prompt), five to ten runs each at temperature 1.0, with at least two player models and a judge from a different model family, blinded to condition. Every run starts in a clean workspace containing only the prompts and harness.

\paragraph{Leakage controls.} (i) A \emph{fictional era} with a consistent invented technology history, where any judged leakage is a false positive. (ii) A \emph{post-cutoff era} after the player model's knowledge cutoff \citep{cheng2024dated}, where foresight and recall can be separated. (iii) \emph{Blind briefings} generated from sources dated before each era by a procedure that does not see later history. (iv) A \emph{vocabulary probe} that flags memo terms whose first recorded use postdates the era.

\paragraph{Scoring.} Totals computed by the harness as $\tilde{T}$ from structured subscores; hindsight reported separately and excluded from the total; a new \emph{frontier-capture} measure recording whether the chosen layer matched, neighboured or missed the layer where value pooled.

\paragraph{Judge validity.} Two to three human raters (technology historians or experienced investors) score a stratified sample of eras; we will report human--model agreement and the effect of swapping judge families \citep{zheng2023judging}.

The expected cost is roughly 46 model calls per run, or about 900 to 1,850 calls across conditions, plus human rating time.

\section{Limitations}

The four trajectories share a small number of model families and are not a controlled sample. No run instantiated sixteen independent agents; each department memo was voiced by one context. Outcomes such as revenues and exits are the judge's calibrated guesses and compound across eras. Qualitative patterns such as ``named the frontier'' are judge-labelled. Runs 002 and 003 have thinner records than Runs 001 and 004. The live-era audits rely on web sources as of September 2026 and may not hold. Forecast eras have no ground truth. Model versions were not recorded. The correlations we report are based on six points per run and should be read as descriptive.

\section{Conclusion}

\sys{} turns a simple question, whether an LLM organization can learn strategy by being scored against history, into a protocol with published artifacts. Four exploratory runs suggest that the answer cannot be read off the scores: improvement and hindsight leakage move together, rubrics can reward caution over foresight, and routine bookkeeping errors change the picture. We hope the protocol, the artifacts and the controlled design are useful to others building ``learn from history'' evaluations for agents.

\section{Judge instructions (excerpt, Run 001)}

The training-era judge was instructed to describe ``what actually happened in the real world during this era window (real winners, the real bottleneck or layer where value pooled, the real capability jumps)'', to score five dimensions from 0 to 10 with one-line justifications, including ``hindsight leakage (10 = no leakage; penalize any post-date knowledge in memos or decision)'', to give an overall era score from 0 to 100 with a calibrated simulated outcome, and to append three to five generalizable lessons to the Playbook. It then wrote the next era's briefing, restricted to information public before that era's start date. Full prompts are in the repository under \texttt{prompts/}.
