# E8 board decision — projected January 2032

**Company:** Caseground — independent qualification for one buyer-defined dispute workflow.

**Decision:** Continue only as a paid, manual acceptance-test service for an existing dispute workflow, not a general agent assurance platform. Test whether a buyer's current evaluation misses material failures and whether the result changes a deployment or procurement decision. Keep actions and case decisions with the customer.

**Thesis:** If agents are more capable by 2032, exposure to consequential workflows may raise demand for evidence that a workflow meets its own quality target at acceptable oversight cost. The uncertain layer is independent qualification. The capability-to-adoption chain depends on authorized representative cases, buyer-defined material error, an accountable budget owner, and results that affect decisions.

**Plan:** Offer one fixed-price blinded test; compare with the buyer's existing QA; record review, setup, security, and cost. Require at least 80% reusable test method and a second paid buyer before productizing a portal. No forecasted maturity or regulation is presumed.

**Kill criteria:** No paid buyer/data permission; no incremental findings; test fails to change a decision; setup >3 person-days, review >2 person-days, gross margin <50%, or repeat buyer customization >20%.

**Kill / keep:** Kill the packet assurance layer if native evaluation meets the target more cheaply. Keep the independent test protocol and case-level measurement only if buyers pay. This remains speculative.

**Dissent:** Product favors developing a reusable portal; CFO rejects build until margin and second-customer evidence. Frontier proposes permission-boundary testing as a possible adjacent test, but no separate product commitment.
