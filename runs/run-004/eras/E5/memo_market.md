# Market & Capital memo — E5 · January 2014

SaaS, smartphones, APIs, and e-commerce make remote workflow delivery practical, not inherently profitable. Include security, privacy, review, support, and cloud costs.

1. **Merchant operations budget:** authorized operations staff uses a permissioned exception workflow; manager pays if labor/time falls. Measure review, outcome, escalation, and integration effort. Risk: action authority and margin.
2. **E-commerce service provider budget:** provider agents use workflow across clients; operations leader pays for productivity. Merchants retain action authority unless explicitly delegated. Risk: client-specific permission and data requirements erase savings.

Keep pilots manual and paid; require repeat workflow and second buyer. Fund automation only when total delivery cost supports plausible margin. This applies the Playbook's second-buyer and total-labor rules.
