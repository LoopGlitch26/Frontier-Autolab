# E2 board decision — 1 January 1996

The Red Team's strongest challenge is not technical: neither support teams nor service providers have shown that they will pay for a separate product. The diagnostic assistant also risks becoming an unmaintainable set of procedures. Executives agree to convert the next period into a buyer-and-usage test, with explicit thresholds set before the pilot. The Web publishing proposal remains a discovery option, not an assumed winner.

## Decision

**Company:** Switchyard Systems — guided resolution for recurring support work in a bounded PC/LAN configuration.

**Reinvention thesis:** PC and LAN environments keep changing; technicians need to resolve recurring failures without repeatedly rediscovering the same steps. Adoption requires accurate guidance in the technician's workflow. The bottleneck is verified, configuration-specific cases and current content. Own the workflow evidence and guided lookup first; only then consider recommendations or a broader knowledge layer.

**Wedge / customer:** Guided local troubleshooting for one supported configuration, tested by one internal IT support team. The service-provider segment is interviewed in parallel, but no multi-customer deployment is promised.

**Three-year plan:** (1) Manually test closed cases and shadow repeat incidents. (2) If accuracy and time-saving thresholds pass, build the local assistant and seek a paid pilot. (3) Expand only when a second buyer pays for the same configuration without bespoke work. Remain within seed capital and a small deployment team.

**Kill criteria:** Apply the Red Team thresholds in `red_team.md`; also stop if no buyer owns budget, permissioned cases are unavailable, or the required content maintenance is uneconomic.

**Kill / keep:** Kill general-purpose network management and broad multi-configuration ambitions. Keep portable incident records, the pilot relationship, and the team's bounded deployment experience. Defer internal Web publishing pending evidence of a content owner, urgent workflow, and payment.

**Dissent:** Leo argues Web publishing could create a strategic option; he supports only interviews until the support pilot reaches its thresholds. Carmen favors testing provider distribution alongside internal IT. The CEO does not choose a channel before proof of usage and payment.
