# Product & Engineering memo — E4 · January 2008

**Priya:** A single hosted queue is buildable, but data access and reliability become our responsibility. **Jonah:** A queue has no value unless an authorized operator can close cases. **Hana:** Manual import cost must be included in economics. **Leo:** Use controlled import/export; postpone bespoke connectors.

1. **Merchant exception workbench:** one exception category, manual/batch intake, owner, evidence, approved action, closure. Hosted delivery may reduce installation, but security and uptime add burden. Next capability: standard import only if two customers need it.
2. **Exception resolution packet:** assemble evidence and decision into a printable/exportable record; humans still act. Test against 50 cases. Risk: documentation may not save time and may duplicate existing systems.

Build only after a paid pilot, named action authority, net handling-time benefit, and second buyer with limited customization. Playbook: manual service does not prove software margins; don't count documented as resolved.
