# Market & Capital memo — E4 · January 2008

SaaS and cloud delivery are growing, but neither validates a buyer. Keep labor capped and pilots time-boxed.

1. **Merchant operations budget:** a named operations employee authorizes defined actions; operations manager pays if exception labor is measurably reduced. Track volume, time, escalation, and labor. Risk: user and approver differ; service labor consumes fees.
2. **Customer-support budget:** support manager might fund fewer unresolved inquiries, but may not control refunds or order changes. Require explicit permissions and track repeat contacts, handoffs, and outcomes.

Seek one paid pilot and a second-customer test using the same workflow and permission template. Track startup hours against fees. Continue only if authority is clear, buyer pays, and second deployment is mostly standard. Playbook: manual delivery is a workflow test, not margin proof.
