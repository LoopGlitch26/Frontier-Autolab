# E1 world briefing — 1 January 1990

**Information cutoff:** 1 January 1990. This briefing intentionally excludes later outcomes.

Business computing is heterogeneous: DOS-compatible PCs, Macintosh systems, workstations, and minicomputers coexist. Windows 3.0 has not shipped. Ethernet and other local networks connect offices; NetWare is a significant network operating environment, but compatibility, configuration, and support are recurring practical burdens. TCP/IP is established in research networking, while general commercial Internet access remains limited. CD-ROM can distribute sizable reference collections, but content is fixed until an update. Machine vision is possible in specialized settings; compute, lighting, and integration limit general deployment.

A frontier signal is Tim Berners-Lee's March 1989 CERN proposal for linked information across an organization. It describes a possible information-management system; it is not a public Web service or evidence of broad adoption. The company has $1.5 million, suitable for a focused software team, not heavy manufacturing or a consumer network.

Sources: [CERN, Information Management: A Proposal (1989)](https://info.cern.ch/Proposal.html); [W3C history of the proposal](https://www.w3.org/History/1989/proposal-msw.html). These sources establish the proposal's date and scope; all adoption assumptions remain hypotheses.
