# E1 board decision — 1 January 1990

The Red Team rejects three common leaps: that case records will transfer between networks; that a request log earns regular use; and that a broad LAN workflow can be integrated repeatably. Executives agree the first two can be tested cheaply, but the company should not mistake a technical demo for a buying signal. The board also records dissent: the linked library may be more durable if internal information sharing becomes important, but there is no evidence yet of an urgent payer.

## Decision

**Company:** Switchyard Systems — practical support tools for one installed LAN environment.

**Reinvention thesis:** Existing LANs connect more office machines, but heterogeneous configurations make diagnosis costly. Adoption depends on technicians trusting and using a shared record. The bottleneck is evidence about configurations and repeat failures, not automated intelligence. Own a narrow incident-and-configuration casebook; customer-authorized records may make repeat fixes faster and reveal which compatibility problems deserve automation later.

**Wedge and first customer:** A support team operating one NetWare LAN. Shadow its technicians, record a limited set of incidents and verified resolutions, and compare repeat-incident handling with its baseline. The initial software is a single-machine case log with export; LAN sharing is an opt-in test after the workflow works.

**Three-year plan:** First validate the buyer, incident frequency, and labor baseline. Then ship a narrow casebook for one supported environment. Only add configuration capture or recommendations if customers authorize the data and repeat cases demonstrably resolve faster. Seek a paid pilot before broad sales. Capital need remains within the $1.5M seed budget, with a small field-support allocation.

**Kill criteria:** No named budget owner; no measurable improvement in repeat resolution; technicians fail to record cases; customer-specific work dominates; or authorized data collection is unacceptable.

**Kill / keep:** Kill the idea of a broad universal network compatibility suite and defer the linked library. Keep the small software team, installation discipline, and permissioned support-case workflow as hypotheses to test.

**Dissent:** Ines favors a limited parallel discovery effort on private linked information; Carmen warns the buyer remains unproven. The CEO chooses one operational pilot to avoid splitting the team.
