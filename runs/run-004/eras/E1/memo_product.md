# Product & Engineering memo — E1

**Priya Nair:** A team under twenty can ship a local case log and configuration checklist. It cannot support every PC, LAN, and peripheral combination with $1.5M.

**Jonah Reyes:** First user is a network technician, not a generic office worker. Proposal A records incidents, configurations, and verified resolutions. Proposal B is a private linked procedure/reference library for one technical group.

**Hana Kowalski:** Keep the core single-machine and exportable; test sharing on one supported LAN only. Treat automated diagnosis as a later hypothesis.

**Leo Mbeki:** Avoid a proprietary data trap. Use documented formats and customer-authorized records; retain a manual export path. This supports portability but does not create distribution by itself.

**Recommendation:** Validate the technician workflow before expanding. A private library is cheaper to prototype but has uncertain update economics. For either option, the first release must work without broad Internet access. Apply the small-team lesson: one environment, explicit support boundary, and measured operating cost.
