# E2 board decision — Jan 1996

**PageSignal** pivots from local network diagnostics to web uptime monitoring and actionable alerts for small hosting providers and corporate web teams. Thesis: public websites become business-critical → downtime and routing faults are hard to isolate → neutral monitoring earns a recurring fee → incident history improves root-cause triage → remediation workflow is the next layer.

Ship distributed probes and email/pager alerts; first buyers are 15 hosting operators. Raise $2M for sales and probe locations. Kill if hosting providers bundle equivalent checks or customers will not pay separately for alert quality. Keep monitoring code and operator relationships; discontinue broad network adapters. The scientist wants search/discovery of pages; the Red Team argues uptime lacks a buyer if web revenue is not yet material. CEO chooses reliability because service interruption is measurable.
