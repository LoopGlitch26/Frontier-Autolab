# E3 board decision — Jan 2002

**Clinisphere** enters hosted scheduling and insurance-eligibility workflow for independent clinics. Thesis: web-delivered software lowers deployment burden → clinics want fewer manual calls and missed appointments → implementation and data normalization are bottlenecks → a hosted workflow layer wins → exception/outcome data enable broader practice operations.

Start with appointment reminders and eligibility checks in one specialty. Budget: $3M, including integrations and compliance work. Kill if a clinic cannot show measurable staff-hour savings in 90 days or deployments require custom code each time. Keep uptime monitoring and integration skills; stop selling general probes. The CFO warns clinics have fragmented buying and long sales cycles; product argues a narrow specialty can standardize workflows. CEO accepts one specialty only.
