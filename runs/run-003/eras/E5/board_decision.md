# E5 board decision — Jan 2014

**BenefitFlow** builds mobile-first benefits enrollment and document verification for regional employers and benefit administrators. Thesis: smartphones and cloud HR tools make self-service enrollment practical → employees can submit changes and evidence directly → identity and document exceptions block automation → the company owns intake and verification → accumulated exception outcomes support eligibility decisions.

Start with one benefits administrator and one annual enrollment cycle; $6M capital. Kill if enrollment completion fails to improve or if a major HR platform includes equivalent verification. Keep identity matching and secure document intake; discontinue claims adjudication. The market lead prefers a consumer app, while the CFO insists on an administrator-paid channel. CEO chooses B2B distribution with a narrow employee experience.
