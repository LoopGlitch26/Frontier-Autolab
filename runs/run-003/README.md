# Run 003

Description: This qualitative run used a separate, manually orchestrated harness on 2026-09-29, following the Frontier Lab era sequence and rubrics. One model supplied the department perspectives, board deliberations, and judging; these are simulated roles, not independent agents. Historical hindsight cannot be fully controlled, outcomes are illustrative, and forecast eras have no answer key. The 2026 audit uses contemporary research linked in `final_synthesis.md`.

This did not use the Python API harness in `harness/`; it is not a multi-model replication, ablation, or evidence that the Playbook improves strategy. Use `scores.csv` for scores and `final_synthesis.md` for interpretation and limitations. Era decisions and reveals are in `eras/`.

## Review note (29 Sep 2026)

- **Probable exposure to Run 001.** This run was generated in the same workspace as Runs 002 and 004, where the repository's Run 001 records and findings were probably visible. Its company names differ, but treat it as conditioned on Run 001, not as an independent replication.
- **Score aggregation.** Only E1–E2 totals equal the subscore sum × 2; the others were set by the judge. See `../../results/all_runs_scores.csv`.

- **Era window.** The E6 reveal covers 2020–2025 rather than the protocol's Jan 2020 – Aug 2026 window.
- **Protocol depth.** Era files are short decision and reveal summaries; no briefings, department memos or Red Team output were recorded.
