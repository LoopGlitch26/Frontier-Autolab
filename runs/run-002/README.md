# Run 002

Description: This qualitative run used a separate, manually orchestrated harness on 2026-09-29. It follows the nine-era sequence and scoring rubric in the project charter. One model generated the department perspectives, board decisions, and judging; these are simulated roles, not independent agents or a controlled replication. Historical scores and outcomes are calibrated judgments, not measured company outcomes. E7 uses current web research; E8–E9 are speculative forecasts.

The Python API harness in `harness/` was not used. This run has no API-call logs and does not satisfy the experiment's multi-model, model-family, or human-rating design. Treat it as a qualitative run, not evidence that the Playbook improves performance.

Scoring files: `scores.csv`. Trajectory and limits: `final_synthesis.md`. Current-era sources are linked in the E7 section of that synthesis.
